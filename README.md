# BioPay - Biometric Contactless Payments

Experience Google Pay reimagined with next-generation biometric fingerprint and thumb scanning for instant, ultra-secure contactless payments.

## Features
- **Biometric Scanner Simulation**: Real-time thumbprint & fingerprint scanning with ultrasonic acoustic feedback and FIDO2 cryptographic verification.
- **Biometric Contactless Payments**: Send and receive instant peer-to-peer and merchant payments with biometric authentication.
- **Pay Bills & Utilities**: Settle electricity, broadband, mobile recharge, gas, and DTH bills.
- **Scratch Cards & Rewards**: Gamified rewards system with cashback scratched straight to your bank balance.
- **Multi-Account Balance Check**: Multi-bank account management with biometric PIN-less balance inquiry.
- **Audio Feedback**: Custom Web Audio API synthesized biometric scanning and transaction chimes.

## Tech Stack
- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons & Animation**: Lucide React, Motion, Canvas Confetti
- **Audio**: Web Audio API

## Getting Started

### Prerequisites
- Node.js 18+
- npm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/26mcac01-ABenedictPaul/BioPay.git

# Navigate to project directory
cd BioPay

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
npm run build
```
